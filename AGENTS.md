# Codex Instructions

## Guidelines for This Project

When users ask you to do something (even if it's a simple task), don't do it immediately. You MUST first look up the relevant guidelines listed below, and then execute the task following the guidelines. If the guidelines refer to other files, you MUST also read the referenced files. (Unless all these guideline files not yet exist.)

- When setting up the repo, follow the instructions in `plan` folder and `set-up.md`.

- For coding style, follow the instructions in `guideline/coding-style.md`.

- Before making ANY git commit, read and follow `guideline/git-commit.md`.

- before sending any HPC job, read and follow  `guidelines/hpc.md`.

- For analyzing the results of training, refer to the structure of the logs in `guideline/logs-structure.md`.
