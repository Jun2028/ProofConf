# API-generated proofs scored by Goedel — May 2026

This experiment asks whether Goedel-Prover-V2-8B's proof-body logprobs
distinguish passing from failing proofs generated by other models.
GPT-5.4 Mini supplied 34,566 attempts (211 passes); DeepSeek V4 Flash supplied
1,183 attempts (11 passes). These are **Goedel scores**, not the API generators'
native confidence.

## Code and results

1. [Build the manifest](scripts/build_proofconf_prompt_manifest.py): recover
   proof bodies and saved labels from ConfEvolve traces, attach original
   MiniF2F statements, remove `sorry` and evaluator-environment failures.
2. [Score and analyze](scripts/score_prompt_logprobs.py): teacher-force each
   proof through `/v1/completions`, mask imports/statement tokens, and compute
   body-token scores, AUCs, correlations, and filtering tables.
3. [Results](results/2026-05-25/summary.md): 35,749 attempts on 122 theorems;
   [attempt scores](results/2026-05-25/attempt_metrics.csv.gz) and the
   [original audit](results/2026-05-25/original-audit.md) accompany the summary.

Minimum-token logprob gives global AUC **0.705206** and mean within-theorem
AUC **0.517396** over 63 mixed-label theorems. Minimum-window logprob gives
**0.661939 / 0.527688**. The pool contains many duplicates and uses saved trace
labels; no trustworthy fresh Lean verification was available. Three timeout
rows remain failures. The original audit details these limitations.

## Produce the measurements

Run from the repository root. Inputs are the original `evolution_trace.jsonl`
files and MiniF2F statement JSONL. The trace-generating search code belongs to
[ConfEvolve](https://github.com/Jun2028/ConfEvolve); this experiment consumes
those attempts. The scorer requires `requests`, `transformers` with a fast
Goedel tokenizer, and an existing Goedel endpoint supporting prompt logprobs.

```bash
python3 experiments/api-proof-rescoring/scripts/build_proofconf_prompt_manifest.py \
  --trace-glob '/path/to/traces/*/evolution_trace.jsonl' \
  --minif2f-jsonl /path/to/miniF2F-lean4/data/valid.jsonl \
  --minif2f-jsonl /path/to/miniF2F-lean4/data/test.jsonl \
  --drop-sorry --drop-eval-env-errors \
  --lean-output-dir runs/api-rescoring/proofs --output runs/api-rescoring/results.jsonl
python3 experiments/api-proof-rescoring/scripts/score_prompt_logprobs.py \
  --results-glob runs/api-rescoring/results.jsonl --output-dir runs/api-rescoring/scores \
  --base-url http://127.0.0.1:8000/v1 --model Goedel-Prover-V2-8B \
  --tokenizer /path/to/Goedel-Prover-V2-8B --offset-source tokenizer \
  --prompt-logprobs 0 --window-size 24 --stride 6 --tail-tokens 256 \
  --bottom-fraction 0.1 --workers 4
```

The final historical summary excluded one evaluator return-code-127 row after
scoring. The recovered builder includes this exclusion. The saved CSV retains
the original analysis order: ordering affects filtering when scores tie, but
not AUC. A fresh collection or newly ordered manifest is not byte-for-byte
reproduction of the saved corpus. Use the root verifier for the exact saved
tables. [Provenance](../provenance.json) records the original sources and hashes.
