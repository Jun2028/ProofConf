We use the miniF2F dataset for this task. It can be found in miniF2F-lean4-main.zip.

For more details on this dataset, see the paper at docs/2109.00110v2.pdf.

We will only use the problems with moderate difficulty (LLM has a moderate probability of succeeding/failing). See `docs/miniF2F-Graded.json` and the paper at docs/2502.00855v1.pdf for which to choose. Choose an appropriate number of times each questions should be asked to the LLM.
